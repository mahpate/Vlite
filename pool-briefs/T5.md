## Required behaviour

`project(source: &Path, tenant: &str, out: &Path, limits) -> Result<Projection>`
(names are yours; keep the shape small):

1. Tenant prefix is `P = "t" + T + "__"` (check the existing tenant naming in
   `src/server/tenants.rs` / `src/server/reserved.rs` read-only and match it
   exactly). Validate `T` the same way. Stored names keep the prefix physically;
   never rename to root.
2. Supported source profile: complete, **unencrypted, non-timestamped V5** logs.
   Refuse (typed error, nothing written) for: encryption, time-anchor frames,
   compact/precision images, any unknown op, an incomplete/torn tail, or a
   header version other than V5. Report the profile reason precisely.
3. Walk every frame once, building a temporal ownership map from collection
   create/drop frames (collection IDs are reused after drop: ownership is per
   lifetime, not per ID). Graph frames: select only those whose every referenced
   resource is tenant-owned at that sequence; a graph frame that references both
   tenant and foreign resources is a hard refusal (cross-tenant reference).
4. Output keeps sequence `S` continuous: keep the leading `OP_ADVANCE` and every
   selected frame byte-identical; replace every unselected sequence with a no-op
   placeholder `format::record_frame(seq, 0, 0, None)` (or the V5 equivalent your
   reading of `format.rs` shows is a valid no-op — prove it in a test). The
   output's final sequence equals the source's.
5. Write a fresh-lineage V5 header (`new_lineage`), into a private temp file next
   to `out`, fsync, then publish no-clobber (`publish_with`/`publish_held`). An
   existing `out` (or symlink) is refused; on any error no `out` exists.
6. Reopen the output read-only and compute a logical inventory: per resource
   (collection, graph, settings, KV/metadata as the format exposes them) a
   sorted SHA-256 over canonical length-prefixed fields (never `Debug`, never
   unordered maps, never f32 decimal text — use `to_bits`), plus a root digest.
   Compute the same inventory over the source restricted to `P` and require
   equality; mismatch => error and the output is removed.
7. Enforce an explicit size/budget limit (bytes scanned / bytes written) passed
   by the caller; refuse when exceeded rather than running unbounded.
