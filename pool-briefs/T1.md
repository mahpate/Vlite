## Required behaviour

Object key: `{prefix}authority.json` in the coordination store (`AuthorityStore::new(store, prefix)`).
Bounded reads: `MAX_AUTHORITY_BYTES = 64 * 1024`.

Schema `vlite.writer-authority/1`, `#[serde(deny_unknown_fields)]`:

```rust
struct HeadRef { epoch: u64, set_id: String, manifest_sha256: String,
                 index_sha256: Option<String>, sequence: u64, chain_sha256: String }
enum Phase { Recovering, Serving }            // serde lowercase
struct Record { schema: String, installation_id: String, scope_id: String,
                lineage: String,               // 16 lower hex (lineage_hex)
                writer_id: Option<String>,     // None ONLY for a prepared, unclaimed record
                epoch: u64, revision: String, phase: Phase,
                base: Option<HeadRef>, head: Option<HeadRef>,
                claimed_unix_ms: Option<u64> }
```

`Record::validate` (called on every decode and before every encode) fails closed:
exact schema; `installation_id`/`scope_id` 1..=128 chars of `[A-Za-z0-9._-]`;
lineage 16 lower hex; `epoch >= 1`; `revision` and `writer_id` exactly 32 lower hex
(two `random_hex` calls); `HeadRef` uses `valid_set_id`, `is_sha256` for every hash;
`writer_id == None` only when `phase == Recovering && head == None`;
`phase == Serving` requires `writer_id` and `head` with `head.epoch == epoch`;
`phase == Recovering` requires `head == None`; `base` (if any) has
`base.epoch < epoch`; `epoch == 1` requires `base == None`. The ETag is never stored
in the object. Timestamps are diagnostic only.

`Observed { record: Record, etag: String }` is a validated GET result.
`Claim { writer_id, epoch, revision }` is what a process holds after claiming.

API on `AuthorityStore` (blocking, like `ObjectStore`):

1. `read() -> Result<Observed, AuthorityError>` — NotFound => `Missing`
   (never auto-create); invalid bytes => `Invalid`; Unknown/Failed => `Unavailable`.
2. `create(installation_id, scope_id, lineage) -> Result<Observed>` — explicit
   first initialization: E1, `Recovering`, `writer_id: None`, no base/head, fresh
   revision, `Cond::Create`. Conflict => `Exists` (never overwrite).
   Unknown => readback; exact intended bytes => success, anything else => `Unresolved`/`Exists`.
3. `claim(prepared: &Observed, now_ms) -> Result<(Claim, Observed)>` — requires a
   prepared record (writer None, Recovering); fresh 32-hex writer id per call
   (process incarnation: two calls never share an id); fresh revision;
   `claimed_unix_ms = Some(now_ms)`; `Cond::Match(prepared.etag)`.
   Conflict => `Lost` (one winner; no retry loop). Unknown => readback: exact
   intended record (same revision and writer id) => success; otherwise `Lost`
   or `Unresolved` if unreadable.
4. `verify_writer(claim) -> Result<Observed>` — fresh GET; success only if
   `epoch == claim.epoch && writer_id == Some(claim.writer_id)`; a different
   writer or a higher epoch => `Fenced { observed_epoch }`; Missing => `Missing`;
   unreachable => `Unavailable`.
5. `advance_head(claim, current: &Observed, next: HeadRef) -> Result<Observed>` —
   requires `current` to be this claim, `next.epoch == claim.epoch`, sequence
   not lower than the current head's; Recovering->Serving only via this call;
   fresh revision; `Cond::Match(current.etag)`. Conflict => re-read: different
   writer/epoch => `Fenced`; same writer/epoch => `HeadMoved(Observed)` (caller
   rebases; never blindly retries). Unknown => readback exact => success, else as Conflict,
   unreadable => `Unresolved`.
6. `prepare_transfer(current: &Observed, expected_epoch, expected_revision) -> Result<Observed>`
   — operator transfer (the CLI wrapper with fence/loss acknowledgement is ITEM-025,
   not this task). Requires matching expected epoch and revision; `epoch.checked_add(1)`
   (overflow => `Invalid`); `base` = current serving head, or the current base when
   the current record never served; head None; writer None; Recovering; fresh revision;
   `Cond::Match`. Conflict => `Lost`. Unknown => readback exact.

`AuthorityError` → `ApiError` mapping (add `impl From`): `Missing` 503
`writer_authority_missing`; `Exists` 409 `writer_authority_exists`; `Lost` 409
`writer_authority_conflict`; `Fenced` 409 `writer_fenced`; `HeadMoved` 409
`writer_authority_conflict`; `Unavailable` 503 `writer_authority_unavailable`;
`Unresolved` 503 `writer_authority_unresolved`; `Invalid` 502 `writer_authority_invalid`.
Messages must never include ETags, account keys or object bytes.
