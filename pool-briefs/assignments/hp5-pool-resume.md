## Ruling R-HP5-01 (PROVISIONAL), authoritative

Persisted scalar minima in the `0x0202` descriptor are canonical. Encode, and the bind comparison, map a `-0.0`
minimum to `+0.0` (bits `0x0000000000000000`). A stored `-0.0` minimum (bits `0x8000000000000000`) is
MALFORMED. Bind compares the stored minima with the canonicalized retrained minima. Codes, scales and the public
`ScalarU8` do not change: `+0` and `-0` both quantize to code 0, and constant dimensions keep scale `+0`. Rust's
`f64::min` does not specify which zero a tie returns, so a Python first-equal minimum would freeze an unstated
byte rule and is rejected.
