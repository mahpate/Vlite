Inside the dashboard

One tour. Every workspace.

Follow a connected example database from sign-in through collections, records, search, graphs, monitoring and administration.

Run the dashboard

New to Docker or WSL? The guided setup installs the prerequisites on Windows or Ubuntu and starts the published images.

To build from source, clone the repository and create the API token as shown in the manual setup. Then run:

docker compose --profile dashboard up --build -d api dashboard

Open http://127.0.0.1:8081, or the UI served by the API at http://127.0.0.1:18084/dashboard. Both listen on loopback only. Put HTTPS in front before allowing remote access.

First sign-in

The dashboard opens on a sign-in screen. A new server has no accounts and no default password, so it asks for an access token: paste the token from .secrets/api-token. Then create your super admin account under Administration → Users & access and sign in with your username and password from then on.

What you can do

The sidebar groups seven workspaces: Overview; Collections, Search and Graph under Data; Observability and Administration under Server; and the Developer Console under Tools. Graph says what is missing when graphs are not enabled. Tabs inside each workspace hold its views. Controls your role cannot use explain why.

Collections and records

Create collections, write or import records, and inspect each record's payload, metadata and vector.

Search and indexes

Run exact, approximate and hybrid searches with typed filters. Build HNSW indexes and copy any query as code.

Users and tenants

Super admins add users and tenants and issue API keys in Administration. Editors read, search and write; viewers read and search. Each account sees one tenant or all collections.

Monitoring and administration

Super admins watch metrics and live logs in Observability, and run health checks, backups and maintenance in Administration.

Limits

The dashboard does not generate embeddings. Writes replace records and require confirmation. For offline work, use the CLI tools.
