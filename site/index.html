Features

A complete vector database in one file

Storage, retrieval, security and operations, all in one Rust engine. Advanced features are opt-in, so existing files keep working unchanged.

Storage

Durable by design, honest about failure

Every write is a checksummed log frame, synchronized to disk before it is acknowledged. Batches of up to 4,096 operations commit atomically.

  • Corruption fails closed; an incomplete trailing write is reported, never silently dropped.
  • Indexes are derived from the log, so they can always be rebuilt.
  • Offline verify, compact, backup and format upgrade tools.

# offline maintenance on a stopped database

Retrieval

From exact search to hybrid pipelines

Start with exact nearest neighbours, then add HNSW, typed filters and hybrid ranking as you grow.

  • Dense, named and sparse vectors; L2, cosine and inner-product metrics.
  • BM25 lexical + vector hybrid search with weighted reciprocal-rank fusion.
  • Grouped search, recommendations from positive/negative examples, facets and geo ranking.
  • A bounded read-only query language, plus pluggable embedders, rerankers and MMR.

Indexes & acceleration

Fast search without giving up correctness

Approximate search is always optional and rebuildable; exact search remains available for verification.

  • HNSW with background rebuilds, persisted snapshots and filter-aware traversal.
  • Scalar u8 quantization and a disk-ANN sidecar for larger collections.
  • Opt-in GPU exact search through wgpu, and metadata indexes for filtered queries.

Recovery & replication

Rewind, stream and replicate

The commit log is a first-class asset: restore from it, subscribe to it, and ship it.

  • Point-in-time restore to a sequence or timestamp, into a new validated file.
  • A durable change feed, with gRPC watching and signed HMAC webhooks.
  • Read replicas through log shipping, with promotion.

Security

Secure defaults for self-hosting

The server refuses unauthenticated remote access and keeps secrets out of logs and traces.

  • Encryption at rest with ChaCha20-Poly1305 and Argon2id passphrases.
  • Scoped credentials, read-only tokens, rate limits, vector quotas and tenants.
  • HTTPS and gRPC TLS with rustls, optional gRPC mTLS, and non-root containers.

Quickstart

Running in under a minute

Install a release wheel, tarball or container image, then create a file and search it.

# pip install vlite_embedded-0.3.0-py3-none-<platform>.whl  (from the v0.3.0 release)
from vlite_embedded import NativeLibrary

native = NativeLibrary()
with native.create("documents.vlite", dimensions=3) as db:
    db.put("10", [1, 0, 0], metadata={"lang": {"type": "string", "value": "en"}})
    print(db.search([0.9, 0.1, 0], 5))
// npm install ./vlite-embedded-0.3.0-<platform>.tgz  (from the v0.3.0 release)
import { NativeLibrary } from "@vlite/embedded";

const native = new NativeLibrary();
try {
  const db = await native.create("documents.vlite", 3);
  await db.put("10", [1, 0, 0]);
  console.log(await db.search([0.9, 0.1, 0], 5));
} finally {
  await native.close();
}
// Cargo.toml: vlite = { git = "https://github.com/mahpate/Vlite", tag = "v0.3.0" }
use vlite::Database;

fn main() -> vlite::Result<()> {
    let mut db = Database::create("vectors.vlite", 3)?;
    db.put(10, &[1.0, 0.0, 0.0], b"document A")?;
    db.put(20, &[0.0, 1.0, 0.0], b"document B")?;
    let hits = db.search(&[0.9, 0.1, 0.0], 5)?;
    assert_eq!(hits[0].id, 10);
    db.close()
}

Why a single file

Simple to ship, copy, back up and reason about

Durable by default

Every acknowledged write is a checksummed commit synchronized to disk before returning.

Honest recovery

Corruption fails closed. Incomplete trailing writes need explicit repair; committed data is never silently dropped.

Rebuildable indexes

HNSW and metadata indexes derive from the log, so a damaged index never costs you data.

Portable

One versioned binary format across Windows, Linux and macOS, and every language binding.

VLite keeps the live dataset in memory and replays the log on open, with one owner per file. Size deployments for the full dataset. See the technical reference for exact contracts and limits.
