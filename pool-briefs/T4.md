deploy file.** Your only output is the report described below.

## Goal

1. **ITEM-032:** verify current Azure Container Apps (ACA) quotas and limits
   against **current Microsoft Learn documentation** (fetch it; cite URLs and
   the page date/"last updated" where visible). At least: apps per environment,
   environments per subscription/region, replicas per app (min/max), revisions,
   vCPU/memory per replica and per environment (Consumption and workload-profile
   plans), ingress (internal vs external, per-app/env limits, HTTP route rules
   on environments), request timeout and termination grace limits, Azure Files
   / volume mounts, secrets per app and secret size, scale rules (HTTP), and
   any quota-increase process. Mark each value "documented" vs "inferred".
2. **EPIC-008 shape:** propose the IaC layout for
   `deploy/azure-container-apps/ha/` (a NEW subdirectory; the existing deploy
   files must not be modified) matching the PRD:
   - gateway app: external ingress, min 2 replicas, HTTP scale rule,
     readiness/startup probes, termination grace;
   - per-tenant writer app: exactly 1 replica, internal ingress;
   - per-tenant reader app: internal ingress, scale rule;
   - a deploy-time check that backends are internal-only and that no
     environment-level HTTP route targets them (ITEM-031).
   Recommend the template format (the existing `deploy/azure-container-apps/`
   uses PowerShell + `az containerapp`; read `deploy.ps1`, `test.ps1` and
   `README.md` there and match that style unless there is a strong reason).
