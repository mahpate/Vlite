## Recommendations

1. Add the nine exact `data-api` rows and corresponding OpenAPI operations, including request/response/error contracts. Retain the fail-closed inventory checks rather than weakening them.
2. Explicitly classify the nine dashboard keys: add linked controls if this milestone promises them, otherwise use narrowly justified backend/CLI-only exclusions. Do not equate an exclusion with UI validation.
3. Fix the shared-engine helper visibility/lint boundary for the graph-only harness, without globally disabling warnings. This is a compaction prerequisite regression, independently demonstrated before cloud work.
4. Add an explicit cloud admin no-resource-leak/authorization inventory test under memory bindings; do not fabricate collection/graph `CASES` requirements for set/pin identifiers.
