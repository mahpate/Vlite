Why VLite

VLite started as a question: how small can a production-grade vector database be? The answer is a single, checksummed .vlite file with durable atomic commits, exact and HNSW search, typed filters and hybrid retrieval — usable as an embedded library or as a REST/gRPC service, without changing the file format.

  • Written from scratch in Rust; no SQLite or third-party storage engine underneath.
  • Committed data is never silently discarded; corruption is distinguished from an incomplete trailing write.
  • Benchmarks are published with methodology, raw JSON and the places where VLite still needs work.
