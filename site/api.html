VLite API Reference

One engine, several surfaces. Embed VLite in-process from Python, Node.js, Rust or C, or run vlite-server and talk to it over REST or gRPC. All surfaces share the same single-file storage, durability and search semantics.

File format, recovery, limits

Conventions

  • Record IDs are unsigned 64-bit integers. SDKs and REST pass them as decimal strings (e.g. "42") so JavaScript keeps all 64 bits.
  • Distances: lower is always nearer, for every metric.
  • Writes are durable when the call returns. Batches commit atomically, all-or-nothing.
  • Optional keyword arguments that are omitted fall back to the collection's settings (metric, quantization, rerank multiplier).
  • File formats: create() defaults to format 3. Format 4 adds named collections and resumable imports; format 5 adds expiry, geo metadata, named/sparse vectors and the other advanced APIs.

Python · NativeLibrary

Install the platform wheel from Releases with python -m pip install <wheel>. NativeLibrary loads the bundled native library and opens databases. One instance per process; do not use it after fork().

create()

NativeLibrary.create(path, dimensions, *, format=None, key=None,
                     passphrase=None, commit_timestamps=False) -> Database

Creates a new database file. Never overwrites an existing file.

ParameterTypeDescription
pathstr | PathLikeDestination file, e.g. "docs.vlite".
dimensionsintVector dimensionality of the default collection.
formatint | NoneFile format; default 3. Use 5 to enable all newer features.
key / passphrasebytes / strOptional at-rest encryption credentials (choose one).

Returns an open Database.

open()

NativeLibrary.open(path, *, key=None, passphrase=None, read_only=False) -> Database

Opens an existing file and validates committed records. Default: exclusive writer lock until closed. With read_only=True, multiple processes can open shared-lock snapshots; writers are excluded and conflicting opens return locked. Mutations return read_only without invalidating the handle. Reopen to see later commits; in-memory ANN builds are allowed, but the datafile is never written. Calls within one Python process remain serialized by the C ABI; use multiple processes for parallel embedded reads.

Host-owned byte-image databases. Persist them with Database.to_bytes().

Python · Database

A database handle returned by create() or open(). Calls are serialized by an internal lock, so one handle can be shared across threads. Use it as a context manager to close it automatically.

native = NativeLibrary()
with native.create("docs.vlite", dimensions=3) as db:
    db.put("1", [1.0, 0.0, 0.0], metadata={"category": {"type": "string", "value": "docs"}})
    print(db.search([0.9, 0.1, 0.0], k=5))   # [{'id': '1', 'distance': 0.02}]

Applies all operations atomically, in order, in one durable commit.

use vlite::Database;

let mut db = Database::create("docs.vlite", 3)?;
db.put(1, &[1.0, 0.0, 0.0], b"hello")?;
for hit in db.search(&[0.9, 0.1, 0.0], 5)? {
    println!("{} {}", hit.id, hit.distance);
}
db.close()?;

HnswConfig { m, ef_construction, seed } implements Default. _with_metric variants exist for the HNSW methods.

Metadata values

Metadata is a flat map of field name to a tagged value. Nested maps and nulls are rejected; types never coerce.

TypeJSON form
string{"type": "string", "value": "docs"}
integer{"type": "integer", "value": "2026"} — decimal i64 string
float{"type": "float", "value": 1.5}
boolean{"type": "boolean", "value": true}

Filter conditions

A filter is an AND of at most 64 conditions. Missing fields and mismatched types do not match; an empty filter matches everything.

[
  {"op": "eq",    "field": "category", "value": {"type": "string",  "value": "docs"}},
  {"op": "range", "field": "year",     "min":   {"type": "integer", "value": "2025"}}
]

range accepts an inclusive min and/or max of one numeric type.

Search hits

{"id": "1", "distance": 0.02}   // Rust: SearchHit { id: u64, distance: f64 }

REST endpoints

Run vlite-server (or the ghcr.io/mahpate/vlite-api image) and send Authorization: Bearer $VLITE_AUTH_TOKEN. The full contract is served at /openapi.json.

curl -s -X PUT localhost:8080/v1/vectors/1 \
  -H "Authorization: Bearer $VLITE_AUTH_TOKEN" -H "Content-Type: application/json" \
  -d '{"vector":[1,0,0]}'

curl -s -X POST localhost:8080/v1/search \
  -H "Authorization: Bearer $VLITE_AUTH_TOKEN" -H "Content-Type: application/json" \
  -d '{"vector":[0.9,0.1,0],"k":5}'

Operations & admin

Read routes share the server's RwLock; writes and rebuild-triggering ANN queries take exclusive access. Observability adds a process-local structured ring buffer (--log-buffer 2000, maximum 100000), sanitized access logs and a compact metrics snapshot. These admin endpoints require a bootstrap admin credential. Ring entries are not durable audit records.

MCP · vlite-mcp

Build from a checkout with cargo install --path . --features mcp, then run vlite-mcp --db ./vectors.vlite. Stdio JSON-RPC only (no network listener), read-only by default. --writable enables vlite_upsert and vlite_delete and requires exclusive file access.

Default tools: vlite_info, vlite_list_collections, vlite_search, vlite_get, vlite_list, vlite_index_status, vlite_build_index. Index builds affect memory only in read-only mode. Encryption: --encryption-key-file, VLITE_ENCRYPTION_KEY or VLITE_ENCRYPTION_KEY_HEX (choose one). Exact schemas and VS Code / Copilot CLI / Claude Desktop configurations.

C ABI Open accepts "read_only": true; Node accepts open(path, {readOnly: true}). Rust exposes open_read_only, open_read_only_encrypted and is_read_only. All use shared locks and open-time snapshots, not a live view alongside a writer.
