## 2. Top 15 findings, ranked by user impact

1. **Ambiguous destructive selection.** H:176-179: "Select IDs from this page (comma-separated, decimal strings)" and "Delete selected"; C:1504-1507 parses typed IDs. Inspection is not batch selection. Add row checkboxes and a selection count; label action "Delete 3 selected records". Preserve page-bound validation. **M; risk:** selection/ID correctness.

2. **Batch feedback goes to another view.** C:1509-1515 and 1563-1575 write Records operation progress into `import-result`, located at H:239. "operations committed" may be invisible where the action originated. Add local Records status: "Deleted 3 records. Refresh records." Keep partial-commit detail. **M; risk:** misleading acknowledgement after failure.

3. **Saving requires API knowledge.** H:186-191,200-203: "ID (decimal u64)", "Payload (standard base64)", "Put / replace", "Get". Rename to "Record ID (whole number)", "Save record", "Load record"; offer text/JSON content with base64 under "Binary content". **M; risk:** byte fidelity and replacement semantics.

4. **Advanced retrieval is a toolbox wall.** H:491-563 exposes grouping, vectors, geo, recommendations, facets, language, disk ANN. "Uses playground k, metric and filter" (H:539) hides dependencies in another tab. Start with a task picker; show an editable local query summary. Rename "Facets" to "Count field values". **L; risk:** query-state divergence.

5. **Index workflow mixes distinct operations.** H:265-287: "Build HNSW", "Start background rebuild", "Poll / publish rebuild", "Run maintenance tick". D:206-210 foregrounds background rebuilding. Use "Rebuild index in background" as primary; disclose "Direct build" and "Maintenance policy"; move selected build settings here (A:1310-1316). **M; risk:** accidentally changing publication behavior.

6. **MemoryAI dead-end shows an intimidating form.** C:1155-1161: "this sign-in does not provide one" disables submission; H:369-406 still presents scope/ranking fields. `current-memory.png` confirms this state. Show a compact prerequisite panel first: "Memory access required. Ask your operator for a scoped token and memory scope." Reveal form after access. **M; risk:** hiding useful diagnostics.

7. **Basic search foregrounds expert syntax.** H:427,458-473: "k", "Metadata filter (JSON AND array)", then a separate builder. Rename "k" to "Maximum results"; place builder beside query; collapse JSON under "Edit filter as JSON". **M; risk:** synchronization and typed-value precision.

8. **Hybrid results become unreadable.** A:1264-1289 generates five numeric columns and unrounded `String(hit[field])`; `current-hybrid.png` shows fragmented headers, IDs and decimals. Default to ID, rounded score and preview; disclose component ranks/details; retain exact export values independently. **M; risk:** precision/export regression.

9. **Confirmation lacks explicit accessible naming.** H:859-864: dialog heading "Confirm operation" has no `aria-labelledby`/`aria-describedby` linkage. Add heading ID and link both heading and operation text to the dialog. Keep Cancel first. **S; risk:** verify announcement and focus with assistive technology.

10. **Expiry demands timestamp arithmetic and can clear existing expiry.** H:354-355: "Expiry (absolute Unix milliseconds; blank means no expiry)" and "blank expiry clears its existing TTL". Offer "Never", "Keep current expiry", "After duration", with exact milliseconds advanced. Keep "Keep current expiry" backed by fetched state, not omission. **M; risk:** changed expiry semantics.

11. **File import unnecessarily branches early.** H:233-257 separates 100-record import from resumable jobs, exposing "Resume from durable checkpoint"/"Finish job". Use one file picker, choose the supported flow after validation; show resume controls only for a known job. Rename to "Resume import". **L; risk:** chunk identity and committed-data guarantees.

12. **Metadata editing has a manual synchronization loop.** H:192-198: "Load JSON into fields", "Apply fields to JSON draft", then save. Use visual fields by default with synchronized "Edit metadata as JSON"; indicate invalid JSON before switching. Hide "Legacy record preview (JSON)" (H:174) from normal navigation. **M; risk:** unsaved drafts/type preservation.

13. **Collection management defaults to expert JSON.** H:323-328 opens "Settings of the active collection" with "Settings JSON"; creation also offers overlapping settings/index JSON (H:310-315). Close expert settings initially; add basic metric/index-field controls and "Advanced JSON settings". **M; risk:** precedence and partial-update semantics.

14. **Comparison does not identify both records locally.** H:566-567: "Other saved ID", "Compare with editor ID". Show "First record ID" and "Second record ID", prefill the first explicitly; label "Compare records". Keep "Analyze first 32 records" distinct. **S; risk:** preserving intended editor selection.

15. **Graph terminology still requires guesswork.** G:16-21,470,532-538: "Bounded traversal", `max_hops`, `max_output_paths`, "Limits and property projection". Rename to "Explore connections", "Maximum connection steps", "Maximum returned paths", "Advanced limits and returned properties". Keep server-default blanks and operation-specific disclosure. **S; risk:** documentation/API-label mapping.
