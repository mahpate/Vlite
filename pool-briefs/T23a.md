   writer A's authority target points at the fault proxy (the operator

   --ack-report-id --expected-epoch --expected-revision --old-replicas 0`
   (document that `--old-replicas 0` is a simulated acknowledgement), and
   resume the proxy. Required: the in-flight write and every later write
   to A are never 2xx (accept 503 `writer_authority_unavailable`, 409
   `writer_fenced`, the ambiguous-write code, or a closed connection); A
   exits with code 1 within recheck interval + 5 s; writer B started
   afterwards claims epoch 2 and acknowledges with `x-vlite-epoch: 2`.
   Poll A's `/ready` during the pause and assert it is never 200 after
   the pause has been observed by the fence.
