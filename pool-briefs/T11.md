## Scope

A library only (no CLI, no REST route, no gateway/backend guard wiring):

1. **Route schema.** Add `authority_mode: Option<AuthorityMode>` to `Route`
   with `#[serde(default, skip_serializing_if = "Option::is_none")]`;
   `AuthorityMode::Off` serializes as `"off"`. In `Route::valid`:
   - `Dedicated` + `Some(Off)`: requires `epoch == None` and `reader == None`
     and `read_routing == WriterOnly`.
   - `Dedicated` + `None`: unchanged (positive epoch required).
   - `SharedPool` + `Some(_)`: invalid.
   Update every `Route { .. }` literal: `control_state.rs` (about line 1022,
   both test ctors) and `gateway_trust_tests.rs` (109, 117) with
   `authority_mode: None`. Legacy JSON without the field must round-trip
   byte-identically.
2. **Migration record in control state.** Add
   `migrations: Vec<Migration>` to `Snapshot` with
   `#[serde(default, skip_serializing_if = "Vec::is_empty")]` (legacy objects
   still parse and serialize unchanged). `Migration` (`deny_unknown_fields`):
   `id` (validated: 1-64 chars `[a-z0-9-]`), `tenant`, `phase`
   (`prepared|frozen|target_verified|validating|released|rolled_back`,
   snake_case), `source` (the validated shared-pool `Route` template),
   `target` (the dedicated authority-off `Route`), `source_lineage`,
   `target_lineage`, `updated_unix_ms`. Snapshot validation rejects: an
   invalid record, two non-terminal migrations for one tenant, a migration
   whose tenant is not routable, `source.kind != SharedPool`,
   `target.kind != Dedicated` or `target.authority_mode != Some(Off)`,
   equal or zero lineages.
3. **Transitions** as `pub(super)` methods on `control_state::Snapshot`
   (fields stay private) plus thin CAS wrappers in `tenant_migration.rs`.
   Every wrapper takes `expected_generation: u64` and `migration_id`, runs
   `Objects::update`, and inside the change closure refuses unless
   `current.generation == expected_generation` and the record exists in the
   required phase with the same tenant/source/target identity. Each success
   publishes `A + 1`; nothing ever decrements `A`.
   - `prepare(..)`: insert `prepared`; refuse an overlapping non-terminal
     migration of the tenant; the tenant's current directory route must
     equal `source`.
   - `freeze`, `target_verified`: phase steps only.
   - `cutover(.., views: &CredentialViews)` from `target_verified`, one CAS:
     replace the tenant's directory route with `target`; remove every
     credential entry of that tenant from the active snapshot (retires
     source hashes) and insert `views.target`, then apply
     `keep_restrictions(previous)` so revocations and earlier expiries
     accepted since preparation survive; phase `validating`. Preserve tenant
     suspension exactly (never resume). Refuse if `views.target` contains a
     credential of another tenant or a lineage other than `target_lineage`.
   - `rollback(.., views, target_acked_mutations: bool)` allowed from
     `frozen|target_verified|validating`: if `target_acked_mutations` →
     409 `rollback_requires_reconciliation`; from `released` → 409
     `migration_source_released`. From `validating`, one CAS restores the
     route from `source` (shared-pool, writer/audience, no epoch, no
     reader, `writer_only`, the current `binding_generation` of `source`)
     and switches the tenant's credentials to `views.source` (same IDs and
     scopes, lineage `source_lineage`) with `keep_restrictions(previous)`;
     phase `rolled_back`. From `frozen|target_verified` only the phase
     changes (route and credentials were never switched).
   - `release(.., ack_irreversible: bool)` from `validating` only; without
     the ack → 422 `tenant_migration_ack_required`; phase `released`.
4. **Errors.** Map a wrong phase, generation mismatch, missing migration or
   identity mismatch to 409 `tenant_migration_conflict`; map
   `control_state_indeterminate` (unknown write outcome) to 503
   `tenant_migration_indeterminate`. Add
   `reconcile(objects, migration_id, expected_generation, intended_phase)`
   that does an exact readback: `Applied` iff generation is
   `expected_generation + 1` and the record is in `intended_phase`;
   `NotApplied` iff generation is still `expected_generation` and the phase
   is unchanged; otherwise `tenant_migration_conflict`. No transition is
   retried automatically after an unknown outcome.

Out of scope: CLI subcommands, REST routes, the freeze mutation guard in
