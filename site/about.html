Why VLite

VLite started with a question: how small can a production-grade vector database be? The answer is one checksummed .vlite file, used embedded or behind a REST or gRPC server. That same file now holds property graphs too.

  • Written from scratch in Rust, with its own storage engine.
  • Committed data is never silently discarded.
  • Benchmarks ship with methodology, raw data and known gaps.
